# Instructions for AI coding tools

The project rules are in `CLAUDE.md`. Read it in full and follow it, whichever tool you are. Then read `docs/team-guide.md` for where files go, and `docs/api-contract.md` before touching an endpoint or a call to one.

The rules that apply to every AI tool in this repo:

- Never push to GitHub or run a command that writes to GitHub. Humans push.
- Never appear as an author or collaborator: no `Co-Authored-By` line, no "generated with" line, no tool name or email in commits, pull requests or files.
- Do not commit unless the person asks in that message.
- Ask before editing a folder owned by someone other than the person you are working with (ownership table in `CLAUDE.md`). If you do not know who you are working with, ask.
- The product principles in `CLAUDE.md` are never broken.
